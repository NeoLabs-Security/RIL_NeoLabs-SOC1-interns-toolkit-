# NeoLabs SOC Level 1 Learning Path

The curriculum is organised from foundational reasoning to tool-assisted investigation. Technical terminology is retained and explained through examples, diagrams, field walkthroughs and guided practice.

## Stage 1 — Security operations foundations

1. What SecOps and a SOC do.
2. People, process and technology.
3. SOC L1 responsibilities, alert ownership and escalation.
4. Events, alerts, findings, incidents, evidence and indicators.
5. Severity, priority, confidence and business context.

## Stage 2 — Log literacy

1. Log generation, collection, parsing, normalisation and indexing.
2. Timestamps, time zones, clock skew and timelines.
3. Windows Security, Sysmon, Linux, network, web, application, database and cloud telemetry.
4. Observation versus interpretation versus conclusion.
5. Correlation, baselines, visibility gaps and defensible reporting.

## Stage 3 — Wazuh foundations

1. Wazuh agent, manager, indexer, dashboard and API.
2. Decoders, rules, alerts, archives and indices.
3. Agent groups and centralised configuration.
4. Secure deployment and local stack health.
5. Pod-scoped enrolment with the VCC Security Lab.

## Stage 4 — Dashboard and query literacy

1. Dashboard navigation and saved views.
2. Alert filtering, field inspection and raw-event review.
3. Wazuh Query Language and OpenSearch query concepts.
4. Command-line pivots with `jq`, `grep`, `journalctl`, `ausearch` and PowerShell.
5. Query journals and reproducible investigation notes.

## Stage 5 — SOC L1 investigation workflow

1. Receive and validate an alert.
2. Identify affected identities, assets and resources.
3. Establish a time window and collect surrounding evidence.
4. Test benign and malicious explanations.
5. Classify, document, close or escalate.

## Stage 6 — Guided practice

Labs progress from single-source interpretation to multi-source timelines, alert triage, web-application investigations, cloud activity review, detection validation and final case reporting. All included evidence is synthetic or generated within the authorised VCC Security Lab.

## Completion evidence

Students preserve:

- completed investigation notes;
- query journals;
- evidence logs;
- incident reports;
- screenshots with secrets and personal information removed;
- reflection notes explaining uncertainty and next steps.

Official graded submissions are made in the central SOC Assignments repository, not here.
