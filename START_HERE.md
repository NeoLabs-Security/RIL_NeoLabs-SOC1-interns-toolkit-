# Start Here — SOC Analyst Level 1

Welcome to the **NeoLabs × RIL SOC Level 1 Intern Toolkit**.

This repository contains the SOC learning material, local Wazuh tooling, templates and the student-side NeoLabs client. Official weekly submissions belong in the separate **RIL_NeoLabs-Intern-Assignments** repository.

## Windows quick setup

1. Complete the workstation/Wazuh prerequisites documented in this repository.
2. Double-click `setup-windows.cmd`.
3. Open PowerShell in this toolkit folder.
4. Confirm the local launcher is available:

```powershell
.\neolabs.cmd --help
```

Windows interns do **not** need `pip install` or Python Scripts PATH changes. Use the toolkit-local launcher rather than relying on a globally installed `neolabs` command.
