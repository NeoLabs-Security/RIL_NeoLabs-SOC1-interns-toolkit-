# Start Here

Welcome to the **NeoLabs SOC Level 1 Intern Toolkit**.

This repository is the shared learning and technical resource centre for SOC interns. It is not the official assignment-submission repository and it does not grant infrastructure access to the VCC Security Lab.

## Recommended order

1. Read `LEARNING_PATH.md`.
2. Study the Log Literacy manual.
3. Study the expanded SecOps Foundations notes.
4. Complete Wazuh fundamentals and dashboard tutorials.
5. Use the Query and Command Reference during guided labs.
6. Complete practice labs with the supplied synthetic logs.
7. Use the incident-report, evidence-log and query-journal templates.
8. Deploy the approved local Wazuh stack and enrol it only to the pod assigned by NeoLabs.

## Access boundary

SOC interns may use:

- the assigned VCC learner web application;
- the approved student-facing dashboard;
- GitHub, Slack and email for programme work;
- their own approved Wazuh environment;
- the telemetry feed explicitly issued for their assigned pod.

SOC interns do not receive direct access to EC2, AWS consoles, databases, container runtimes, private networks, pod hosts, mentor dashboards or production systems.

## Important security rules

- Never place passwords, enrolment tokens, certificates or private URLs in Git.
- Never change a pod identifier in an attempt to access another pod.
- Never upload raw evidence containing another learner's personal information.
- Use only the synthetic datasets and authorised VCC lab targets identified in an exercise.
- Report suspected credential exposure immediately through the programme's approved channel.
