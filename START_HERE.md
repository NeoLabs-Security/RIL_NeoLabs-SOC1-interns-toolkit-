# Start Here — NeoLabs SOC Level 1 Intern Toolkit

Welcome to the NeoLabs SOC Level 1 learning environment. This repository supports authorised defensive training connected to the detached, synthetic VCC Security Lab.

## What this repository contains

- NeoLabs-branded SOC and SecOps learning materials.
- Log literacy and Wazuh learning paths.
- Dashboard tutorials and query references.
- Synthetic sample logs and guided practice labs.
- Incident-report, evidence-log and query-journal templates.
- A containerised Wazuh environment prepared for secure, pod-scoped enrolment.
- Setup, validation, backup, reset and troubleshooting tools.

## What this repository does not contain

- Individual weekly assignments or student submissions.
- Mentor answer keys or scenario ground truth.
- Production data, secrets or credentials.
- Direct pod, AWS, EC2, database or container-host access.

Official assignments are delivered and submitted through the separate central SOC Assignments repository. Email and Slack provide notifications and links; GitHub remains the source of truth.

## Recommended first steps

1. Read `SECURITY.md` and `LEARNING_PATH.md`.
2. Complete the SecOps foundations and Log Literacy modules.
3. Study the Wazuh architecture and dashboard tutorials.
4. Deploy the local Wazuh stack only after the setup guide is marked stable.
5. Enrol with the VCC Security Lab using the one-time credential issued by the programme operator.
6. Complete practice labs using only the supplied synthetic datasets and authorised pod telemetry.

## Student access boundary

Students interact only with the assigned VCC web application, approved student-facing dashboard, their local Wazuh environment and approved GitHub/Slack channels. They do not receive shell access to lab hosts, direct pod access, AWS console access, databases or mentor systems.
